3. Architecture
End-to-end WLT pipeline
Flow:
•	Data Sources: PostgreSQL, S3 
•	Data Ingestion: Airbyte )Easy Ingestion)
•	Data Warehouse: Snowflake (scalable, cloud-based) 
•	Transformation: SQL + PySpark (big data processing) 
•	Visualization/Dashboard: Power BI 
•	Orchestration: Airflow (scheduling, automation) 
________________________________________
